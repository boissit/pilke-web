# Which picture is on which page

Every screenshot on this site is a still of a real build, so a change to the app's UI can
make any of them a picture of something the product no longer does. This document exists so
that finding out *which* ones is a lookup rather than a hunt through components: the mistake
it is here to prevent is reshooting the screens you happened to think of and shipping the one
you forgot.

Two tables. The first is generated from the build and lists what is drawn where. The second
is written by hand and says what each picture shows, because that is the part a script cannot
read off a file.

## Before shipping a change to the app's UI

1. Find the changed element in **What each picture shows** below.
2. Reshoot every picture whose row names it, and no others. Reshooting the rest only churns
   which mock partner the fixture paired you with.
3. `npm run build && npm run pictures -- --check`, which fails if a page draws a picture this
   document does not account for.
4. Verify by decoding the built file, not the source: `dist/_astro/<name>.<hash>.webp`. The
   optimiser keys its cache on the source path rather than the content, so a changed image at
   an unchanged path can serve stale. `rm -rf node_modules/.astro` before a build settles it.

Not every screen the flows take is carried here. `screenshots.yaml` also shoots the
calendar and the question sets, and neither has a place on the site; the way to bring one
back is to copy it out of `pilke-app/shots/` and give it a row below.

Screenshots come from `pilke-app/.maestro/demo/`: `screenshots.yaml` takes most of them,
`screenshotDate.yaml`, `screenshotPlatter.yaml`, `screenshotStory.yaml` and
`screenshotFeedback.yaml` the ones needing a fixture that flow cannot build. They land in
`pilke-app/shots/` and are copied here by hand.

## What each picture shows

The last column is the one that matters when the app changes: it names the parts of the app
that are visible, so a change to any of them can be traced back to the pictures carrying it.

| Picture | App screen | Taken by | What is visible in it |
| --- | --- | --- | --- |
| `treffit` | Home, populated | `screenshots.yaml` | **The balance counter: the glimmer pile, the `Kipinat:` label and the figure.** The wordmark, three stacks of match cards with partner photos, names, ages, venues and timeslot chips, the `Loyda treffit!` button, the tab bar. The only picture on this site with the currency in it |
| `platter` | Candidates | `screenshotPlatter.yaml` | A candidate's photo card, name and age, the times both people share, the activity chips, the `Ehdota!` button, the pager dots. Drawn on the brand yellow, so a change to that colour shows here |

## The currency

The coins in the price lines are not screenshots. They are renders from
`pilke-app/tools/glimmer-pile`, and that directory's README carries the command this site's
copy comes from. `GlimmerPile.astro` names the amounts the site holds a picture of, so an
amount with no file fails the build rather than drawing a different one.
